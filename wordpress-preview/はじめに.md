# 60代からのいいもの探し — Cocoon Child用トップページ

2026年11月6日制作。デザイン修正版 1.1。既存コードを調査して作成した、導入前のテスト用パッケージです。本番WordPress・データベース・main・公開中GitHub Pagesには変更を加えていません。作業用ブランチ hana-cocoon-preview にのみ保存しています。

## 最初に見るもの

1. ZIPをパソコン上で解凍します。
2. `preview/index.html` をブラウザで開くと、デザインの見本を確認できます。フォルダ構成を変えずに開いてください。
3. `導入手順.html` を開き、別のテスト用WordPressに設置します。
4. 完成を確認するまでは、本番へアップロードしません。

プレビューの6記事と記事イラストは表示見本です。WordPress版へサンプル投稿を登録する処理はありません。メイン画像は仮の枠です。ご指定の文字なし「私とハナ」イラストは後から管理画面で選べます。

## 同梱ファイル

- `cocoon-child-additions/page-hana-home.php`：専用の固定ページテンプレート
- `cocoon-child-additions/hana-home/setup.php`：画像・タイトル・カテゴリ・ROOMの設定とCSS読み込み
- `cocoon-child-additions/hana-home/assets/`：このページ専用のCSSと6つのカテゴリ線画
- `functions-append.txt`：既存functions.phpへ追加する1行。置き換え用ファイルではありません
- `preview/`：ブラウザ用の静的見本とPC・スマートフォンの画像
- `導入手順.html`：初心者向けの設置・日常更新・復元手順
- `調査と実装方針.md`：参照コードと設計上の判断
- `検証結果.md`：実施済みの検証と、テスト用WordPressで確認する項目

このZIPは「完成したテーマ」や「プラグイン」のZIPではありません。「外観 → テーマ → 新規追加」でそのままインストールしないでください。既存Cocoon Childに2つの新しいパスを追加する方式です。
